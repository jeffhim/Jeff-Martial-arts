營養師修武之路

設定雲端儲存，隨時隨地記錄你嘅武學心得

1

建立 Firebase 專案

  1. 去 Firebase Console 登入 Google 帳號
  2. 撳「新增專案」→ 輸入名稱（例如 martial-arts）→ 建立
  3. 喺專案入面撳「新增應用程式」→ 選「網頁 </>」
  4. 輸入名稱 → 撳「註冊」→ 複製 firebaseConfig 嘅內容
2

開啟 Firestore 同匿名驗證

  1. 左邊選單 →「Firestore Database」→「建立資料庫」→ 選「正式模式」→ 啟用
  2. 左邊選單 →「Authentication」→「Sign-in method」→ 開啟「匿名」
  3. 去「Firestore」→「規則」，貼上以下規則並發佈：
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == userId; } match /published/{shareId} { allow read: if true; allow write: if request.auth != null; } } }
3

貼上你嘅 Firebase Config

將 Firebase 嘅 config 物件貼喺下面（JSON 格式）：

營養師修武之路
本地模式

古人練武為強身健體 保家為國

今有營養師希望透過修武以修身及身心

透過所練所習來平靜現實和內心的不穩

貫徹止戈為武 上善若水的哲學
